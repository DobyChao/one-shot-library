# 难度收口 + Treat 模式规格（v1.1）

用户反馈：道中/Boss 易秒死；要 **Treat** 能看完全关；音乐要有（可合成）。

---

## 1. Treat 模式（观关 / 通关体验）

**开关**：`?treat=1`（可与 `god=1` 并存；Treat 已含无敌时 god 冗余）  
**标题提示**：标题或 HUD 显示 `TREAT`；README 写明。

### 必做（程序已部分落地 → 对齐本表）

| 项 | 规格 | 现状备注 |
|----|------|----------|
| 无敌 | 自机不受敌弹/体碰伤害 | 已有 `treatOn` 早退 |
| 残机 | 开局 **99**（或显示 ∞） | 已 99 |
| 敌弹速 | ×**0.55** | 已 |
| 扇/环密度 | count ×**0.5**（下限扇 1 / 环 4） | 已 |
| 判定点 | **常显**（不依赖 Shift） | 已 |
| Bomb | 开局 bombs≥3；X 或 C 放 Bomb 清弹（若键未接请接上） | 待确认 |
| 超时 | Boss 时限到不罚残，直接切下一阶段（便于看完演出） | **待做** |
| 道中 | 杂鱼 HP ×0.6 或自机伤 ×1.5，减少磨血时间 | **待做** |
| 提示 | 标题副文案：「Treat：无敌·低密·常显判定 · ?treat=1」 | **待做** |

### Treat 不做

- 不改符卡名/剧本对话  
- 不关 Music Room  
- 不自动跳过 Boss（要能「看完」弹幕，不是跳关）

### 验收

- [ ] `?treat=1` 从标题可打到 Stage6 Clear / Ex Clear（允许菜，但不因一秒死卡关）  
- [ ] 判定点始终可见  
- [ ] HUD 有 TREAT 标记

## 2. Normal 难度收口（默认 `?treat` 关闭）

目标：新手不「一碰就死到不想玩」，仍保留整数作可读压强。  
**全局默认倍率**（相对 v1 表内裸参数）：

| 层 | 弹速 | 环/扇发数 | 杂鱼 HP | 自机擦弹判定 | 备注 |
|----|------|-----------|---------|--------------|------|
| **Normal（收口后）** | ×**0.85** | ×**0.85**（环下限不变） | ×**0.9** | 维持 | 一次全局开关，少改各面表 |
| **Simple** `?simple=1` | ×**0.7** | ×**0.7** | ×**0.75** | — | 扩展现有 simple（勿只改省略箭） |
| Treat | 见 §1 | 见 §1 | — | 常显 | 覆盖 Normal |

实现建议：在 `Bullet` 构造 / `emit*` 读 `diffMul()`，与 `treatOn()` 互斥（Treat 优先）。

### 热点再削（全局倍率之外）

| 点 | 问题 | 改法 |
|----|------|------|
| 1 面 Spell1 逆流 | 回收+雨叠加 | 垂落雨间隔 2.2→**2.8s**；径向初速 ×0.9 |
| 2 面墙弹 | 反射难读 | 道中 `reflect` 弹速 ×0.9；预 Boss 环 10→**8** |
| 3 面债符竖带 | 带宽紧 | Normal 带宽 36→**44px**；收债网格再疏 20% |
| 4 面朱圈 | 点名狠 | 预警 0.5→**0.65s**；删除线间隔 +0.5s |
| 5 面脂区 | 可叠减速 | 下限速 0.55→**0.65**；单圈半径 36→**30** |
| 5 面缩圈 | 最低 55 挤 | 最低半径 **70px**；缩圈间隔 5→**6s** |
| 6 面终符碎裂 | 高速屑 | 碎裂弹速 3.2→**2.6**；凝固相 1.0→**1.2s** |
| Ex 省略箭 | 已锁 0.5/0.65 | **不再缩短**；e9 三口框预警 +0.15s |

表文件：本收口以本 md 为准；大改数值不必逐行改 STAGE*.md，程序按本节挂倍率 + 热点常量即可。

### 残机经济

- Normal 开局 **lives=5**（原 3）、bombs=3  
- 面间 Clear 奖励 +1 bomb（上限 7）  
- 中弹无敌帧 **2.0s**（若更短请拉长）

## 3. 音乐（合成 BGM）

对齐 `MUSIC_ROOM.md` 17 首 id。  
**无实录音频也要能播**：Web Audio 程序合成 loop（8～16 小节），按 `id` 切换。

| 优先级 | id | 气质提示（合成用） |
|--------|-----|-------------------|
| P0 | `bgm_title` | 中慢、琥珀大调琶音 |
| P0 | `bgm_s1` / `bgm_s1b` | 水波节奏 → Boss 略紧 |
| P0 | `bgm_s6b` | 庄重、小调、终符可切紧张层 |
| P0 | `bgm_exb` | 压迫、低音脉冲 |
| P1 | 其余道中/Boss | 按面色：林青 / 算盘点奏 / 书卷慢 / 庭园剪 / 天球 |
| P2 | `bgm_ending` / `bgm_staff` | 轻、短 loop |

规则：

1. Music Room Z：有合成器则播对应 id；失败 toast。  
2. 进面/进 Boss 自动切曲（道中→Boss）。  
3. 静音键建议 **M**；Treat 不关音乐。  
4. 曲名显示仍用 SCRIPT / MUSIC_ROOM 中文名。
